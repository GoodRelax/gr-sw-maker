## 10. 用語集の非採用欄を武装する

**非採用欄は記録ではなく、実行される規則である。** `check-terms.mjs` が用語集 §1 の非採用欄を検査リストとして読み、その語が `framework-src` のどこかに現れたら落とす。**語を消し終えてから武装する。**

| 採用語 | 非採用にする語 | 前提となる作業 |
|---|---|---|
| ドメインモデル / データスキーマ | `データモデル` | `document-rules:1273,1277` / `process-rules:900,913` / `agents/architect.md` の description を先に直す |
| ANMS / ANPS-part / ANPS-chapter | `ANGS` | `document-rules` 5 件 / `process-rules` 7 件 / `CLAUDE.md` / `agents/srs-writer.md` / テンプレートを先に直す。`commands/council-review.md` の 1 件は ALLOWED だが**文面は直す** |
| 仕様書テンプレート | `骨格` | **無し。`framework-src/` に 0 件。今すぐ武装できる** |
| 仕様書テンプレート | `仕様テンプレート` | §4 の 2（`agents/architect.md:106` / `agents/srs-writer.md:95` × 2 言語）を先に直す |

### 10.1 非採用欄に置けない語

**`check-terms.mjs` は CJK を単語境界なしの部分一致で照合する。** 部分文字列として正当な用法に現れる語を置くと、その用法まで違反になる。

| 語 | 置けない理由 |
|---|---|
| `機械` | 「機械可読」「機械が検証する」の 22 箇所が違反になる |
| `ノード` | StrictDoc のノードの全用例が違反になる |
| `接続` | 「接続・ファイル・メモリ」（資源管理）等が違反になる |
| **`テンプレート`（単独）** | **`CLAUDE.md テンプレート` など別の雛形を指す 55 行 / 14 ファイルが違反になる** |

**これらは §4「紛らわしい対」で区別する。非採用欄には置かない（MUST NOT）。**
